# TAMUSA-ACM Website

Welcome to the TAMUSA-ACM Website repository! This project hosts the official website for the Texas A&M University-San Antonio ACM chapter. Built using the Flask micro-framework, the site features a responsive design with Bootstrap and custom CSS, providing a dynamic and engaging user interface tailored for web development and design enthusiasts.

## Features

- **Responsive Design**: Utilizes Bootstrap and custom CSS to ensure the website looks great on all devices.
- **Dynamic Content**: Powered by Flask, enabling seamless integration of backend logic and frontend design.
- **Custom Styling**: Unique and engaging UI design to enhance user experience.
- **Modular Architecture**: Built with a focus on scalability and maintainability.

## Setup and Installation

To get started with the TAMUSA-ACM website, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/tamusa_acm_org.git
   cd tamusa_acm_org
   ```

2. **Set up a virtual environment**:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install the dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**:
   ```bash
   flask run
   ```

   The website should now be running at `http://127.0.0.1:5000/`.

## Usage

Once the application is running, you can explore the website by navigating to `http://127.0.0.1:5000/` in your web browser. Feel free to explore the various sections designed to showcase the activities and resources of the TAMUSA-ACM chapter.
